LocalLens API

LocalLens helps travelers find and book local experiences.

Status: API is running. Version: v1

API Endpoints

  • GET /api/v1/bookings — List bookings.
  • GET /api/v1/bookings/{id} — View one booking.
  • POST /api/v1/bookings — Create a booking.
  • PUT /api/v1/bookings/{id} — Update a booking.
  • DELETE /api/v1/bookings/{id} — Delete a booking.
  • GET /api/v1/greeting — Open this page.
